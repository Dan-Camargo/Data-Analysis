# Análise de Dados - Python

Repositório com projetos de análise exploratória de dados usando Python e dados públicos brasileiros.

## Tecnologias

- Python
- Pandas
- Matplotlib
- Requests
- Jupyter Notebook

## Projetos

### Educação
- **Análise Escolas** - Infraestrutura escolar (dados INEP)
- **Análise PRONATEC** - Programa de ensino técnico
- **Análise PROUNI** - Programa universidade para todos
- **AnáliseAlunosFatec** - Dados institucionais Fatec

### Governo e Política
- **Análise API Câmara** - Dados da Câmara dos Deputados
- **Análise CEAPS** - Gastos parlamentares

### Entretenimento
- **Análise ANCINE** - Produção cinematográfica brasileira
- **Análise Copa Wikipedia** - Dados sobre Copas do Mundo

### Saúde
- **Análise Cirurgias** - Procedimentos do sistema de saúde

### Regional
- **Análise RS** - Dados do Rio Grande do Sul

## Habilidades Desenvolvidas

- Manipulação e limpeza de dados com Pandas
- Consumo de APIs REST governamentais
- Visualização de dados com Matplotlib
- Análise estatística descritiva
- Tratamento de dados JSON e CSV

## Como Executar

```bash
pip install pandas matplotlib requests jupyter
jupyter notebook
```

## Dados Utilizados

APIs e datasets públicos do governo brasileiro (INEP, Câmara dos Deputados, ANCINE, Ministério da Saúde).
